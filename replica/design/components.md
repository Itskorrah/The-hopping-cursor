# Desktop design direction

The workspace itself is the main control: monitor silhouettes on a neutral
grid make placement legible. Slate blue sidebar, white surfaces, cobalt active
edges and clear connection badges relate to desk hardware, not a marketing
landing-page template. DM Sans for controls; system monospace only for keys and
fingerprints. Left aligned labels, compact navigation, wide arrangement canvas.

Reusable components: accessible buttons, labelled switches, status badges,
computer row, monitor tile with keyboard movement, safety-code dialog, transfer
row, toast/live status, and permission notice. Every action reports its result.
No fictional connected computers outside an explicitly marked browser preview.
